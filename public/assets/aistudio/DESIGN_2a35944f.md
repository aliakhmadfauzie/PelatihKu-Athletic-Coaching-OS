## Brand & Style

Sistem desain ini ditujukan untuk ekosistem analitik performa olahraga dan manajemen atlet tingkat lanjut (*PelatihKu*). Karakter antarmuka memancarkan presisi teknis, kedisiplinan, dan ketegasan operasional layaknya instrumen kokpit digital modern. Menggabungkan etos desain berdensitas tinggi ala Linear dan Stripe, antarmuka ini mengutamakan keterbacaan data instan, hierarki visual tanpa distraksi, serta ketepatan metrik di layar gelap.

Gaya desain mengadopsi **Minimalism & Modern Technical Utility** dengan palet gelap pekat (*dark-mode first*). Penggunaan kontras mikro, *hairline borders*, dan aksen berpendar tajam memberikan kesan mutakhir, stabil, dan berwibawa bagi para pelatih, analis taktis, dan federasi atlet yang membutuhkan konsentrasi analitis tinggi.

## Colors

Palet warna dibangun di atas landasan gelap berlapis (*layered deep slate*) guna meminimalkan ketegangan visual pada sesi pemantauan intensif, sekaligus memberikan kontras optimal bagi visualisasi data.

- **Primary (`#10B981` - Emerald Vibran):** Digunakan untuk status performa optimal, target tercapai, metrik positif, aksi primer (*CTA*), serta indikator aktif/siap tanding.
- **Secondary (`#F59E0B` - Amber/Warning):** Berfungsi sebagai penanda beban kerja berlebih (*overtraining*), peringatan risiko cedera, metrik stagnan, serta aksi sekunder yang memerlukan atensi.
- **Tertiary (`#6366F1` - Indigo Presisi):** Berperan sebagai pembeda kategori pada grafik analitik multitarget, data historis, atau pelabelan taktis.
- **Neutral Surface Hierarchy:**
  - Latar dasar kanvas (*Canvas background*): `#0B0F17` (Deep Obsidian Slate).
  - Latar kontainer kartu & panel (*Surface Container*): `#111827` (Charcoal Slate).
  - Latar interaktif & dropdown (*Surface Elevated / Hover*): `#1F2937` (Muted Steel Slate).
  - Hairline Border: `rgba(255, 255, 255, 0.08)` untuk memisahkan bidang kerja secara presisi tanpa beban visual tebal.

## Typography

Tipografi didasarkan sepenuhnya pada **Inter**, dioptimalkan secara ketat untuk densitas informasi tinggi melalui pengaturan *tight letter-spacing* (tracking negatif pada ukuran menengah dan besar). 

- **Angka dan Metrik Kinerja:** Aktifkan fitur OpenType tabular figures (`font-variant-numeric: tabular-nums`) pada seluruh tampilan tabel, grafik, timer, dan data metrik untuk menghindari getaran visual (*layout shift*) ketika angka diperbarui secara dinamis.
- **Hierarki Bahasa Indonesia:** Gunakan struktur teks langsung dan ringkas khas terminologi taktis olahraga (misal: "Ringkasan Performa", "Beban Latihan", "Kesiapan Atlet", "Laju Denyut Nadi").
- **Font Tambahan:** `JetBrains Mono` disediakan khusus untuk kode telemetri, GPS raw coordinate, dan ID sesi atlet.

## Layout & Spacing

Tata letak mengadopsi model **fluid grid** dengan orientasi *compact density* untuk memaksimalkan ruang analitik tanpa membuat visual terlihat sesak.

- **Grid Desktop (≥1280px):** Menggunakan sistem 12 kolom dengan `gutter-desktop` 24px (`1.5rem`) dan tepi margin luar `margin-desktop` 32px (`2rem`). Bilah samping navigasi (*sidebar*) berukuran tetap 240px yang dapat dilipat menjadi 64px (ikon saja).
- **Grid Tablet (768px - 1279px):** Tata letak 8 kolom dengan gutter 16px (`1rem`) dan margin 24px. Kartu metrik ditumpuk menjadi modular 2x2.
- **Grid Mobile (<768px):** Tata letak 4 kolom fluid dengan margin 16px (`1rem`). Dasbor beralih ke susunan vertikal linear dengan kartu gulir horizontal (*horizontal snap-scroller*) untuk metrik ringkas.
- **Rhythm Spacing:** Padding internal kartu dan panel distandardisasi pada skala rapat (`space-md` 12px untuk sel data padat, `space-lg` 20px untuk kontainer grafik besar).

## Elevation & Depth

Desain ini menolak penggunaan bayangan blur pekat (*drop shadows*) yang dapat mengaburkan ketajaman batas visual di latar gelap. Sebagai gantinya, persepsi kedalaman dibangun melalui **Tonal Layers** dan **Low-Contrast Hairline Outlines**:

- **Tingkat 0 (Kanvas Dasar):** Menggunakan warna `#0B0F17`. Merupakan dasar terendah untuk latar aplikasi dan ruang negatif.
- **Tingkat 1 (Kartu Metrik & Panel Statis):** Menggunakan latar `#111827` dibingkai garis tepi *hairline* `1px solid rgba(255, 255, 255, 0.08)`. Tidak ada bayangan.
- **Tingkat 2 (Elemen Interaktif & Floating Panel):** Menggunakan latar `#1F2937`, garis tepi `1px solid rgba(255, 255, 255, 0.12)`, serta bayangan mikro difus `0 4px 20px -2px rgba(0, 0, 0, 0.5)`.
- **Tingkat 3 (Modal Dialog & Dropdown Menu):** Menggunakan latar `#111827` dengan efek *backdrop-filter: blur(12px)*, garis tepi `1px solid rgba(255, 255, 255, 0.16)`, dan bayangan terisolasi `0 16px 32px -4px rgba(0, 0, 0, 0.65)`.

## Shapes

Filosofi bentuk mencerminkan presisi perangkat laboratorium dan dasbor telemetri modern. Menggunakan geometri **Soft (`1`)** untuk menghadirkan ketegasan profesional tanpa terlihat kaku:

- Elemen kecil dan komponen data (tombol, input teks, badge tag, dropdown item) memiliki radius sudut `0.25rem` (4px).
- Kartu analitik, tabel kontainer, dan modal dialog menggunakan `rounded-lg` yaitu `0.5rem` (8px).
- Badge status berbentuk kapsul (*pill status indicator*) khusus pada metrik biner seperti status sinyal sensor ("Aktif" / "Terputus") menggunakan radius penuh `9999px`.

## Components

### Tombol (Buttons)
- **Tombol Utama (Primary):** Latar belakang `#10B981`, warna teks `#0B0F17` (bold, kontras tinggi). Saat di-hover berubah ke `#059669`. Efek aktif berupa pengurangan skala tipis (`scale(0.98)`).
- **Tombol Sekunder (Secondary):** Latar belakang `#1F2937`, garis tepi `1px solid rgba(255, 255, 255, 0.08)`, teks putih `#F9FAFB`. Saat di-hover, latar berubah ke `rgba(255, 255, 255, 0.1)`.
- **Tombol Peringatan (Warning/Amber):** Latar belakang `#F59E0B` dengan teks `#0B0F17` untuk aksi korektif taktis atau interupsi latihan.

### Kartu Metrik & Panel (Cards)
- Latar kartu `#111827`, border hairline `rgba(255, 255, 255, 0.08)`.
- Struktur internal: Baris atas untuk label indikator (`label-sm`, abu-abu netral `#9CA3AF`) bersanding dengan ikon status. Baris tengah untuk nilai numerik besar (`headline-md`, angka tabular). Baris bawah untuk delta perubahan persentase (hijau untuk kenaikan performa, amber untuk beban/kelelahan).

### Chips & Badges Status
- Latar semi-transparan dengan ketebalan 10%: Hijau Emerald (`rgba(16, 185, 129, 0.1)`), Amber (`rgba(245, 158, 11, 0.1)`), atau Netral (`rgba(255, 255, 255, 0.05)`).
- Teks badge menggunakan warna padat yang sesuai (`#10B981` atau `#F59E0B`), ukuran `label-sm`, dilengkapi titik pendar (*pulsing indicator dot*) 6px di sisi kiri teks.

### Formulir & Bidang Input (Inputs, Checkboxes & Radios)
- **Input Fields:** Latar belakang `#0B0F17`, border `1px solid rgba(255, 255, 255, 0.08)`, teks `#F9FAFB`, placeholder `#4B5563`. Fokus memicu ring bercahaya emerald `0 0 0 1px #10B981` dan border berubah menjadi solid `#10B981`.
- **Checkboxes & Radios:** Kotak/lingkaran dasar `#0B0F17` dengan border `rgba(255, 255, 255, 0.2)`. Saat tercentang, latar terisi `#10B981` dengan ikon ceklis putih pekat.

### Baris Data & Daftar (Lists & Tables)
- Sel tabel memiliki tinggi kompak (36px–40px per baris). Pemisah antar baris menggunakan border hairline `1px solid rgba(255, 255, 255, 0.05)`.
- Interaksi hover baris menggunakan transisi halus menuju `#1F2937` (opacity 60%).

### Bilah Telemetri Atlet (Custom Analytics Indicator)
- Komponen visualisasi baris horizontal dengan latar track `#1F2937` setinggi 4px. Isi bar diwarnai transisi gradien halus dari `#10B981` hingga `#F59E0B` untuk menunjukkan ambang batas kelelahan (*lactate threshold / heart-rate zone*).
